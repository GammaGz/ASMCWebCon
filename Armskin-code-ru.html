data/armskin/function/give.mcfunction

Команда игрока /function armskin:give выбирает один из 15 типов с равной вероятностью. Раздел draw в служебном хранилище используется только во время одной выдачи.

№Исходный текстЧто делает строка
1execute unless entity @s[type=minecraft:player] run return 0Проверяет, что исполнитель — игрок. Для консоли применяйте execute as с именем получателя.
2data modify storage armskin:work draw set value {pool:[{id:"minecraft:wooden_sword"},{id:"minecraft:stone_sword"},{id:"minecraft:copper_sword"},{id:"minecraft:iron_sword"},{id:"minecraft:golden_sword"},{id:"minecraft:diamond_sword"},{id:"minecraft:netherite_sword"},{id:"minecraft:wooden_spear"},{id:"minecraft:stone_spear"},{id:"minecraft:copper_spear"},{id:"minecraft:iron_spear"},{id:"minecraft:golden_spear"},{id:"minecraft:diamond_spear"},{id:"minecraft:netherite_spear"},{id:"minecraft:bow"}]}Готовит массив из 15 объектов с настоящими ID. Индекс начинается с нуля.
3execute store result storage armskin:work draw.index int 1 run random value 0..14Равновероятно выбирает индекс 0–14 включительно и записывает его без масштабирования.
4function armskin:pick with storage armskin:work drawПередаёт индекс функции, которая выбирает запись из массива.
5data remove storage armskin:work drawОсвобождает временные данные выдачи.

data/armskin/function/inspect.mcfunction

Отмеченный предмет оформляется в своём слоте. Первый запрос может задавать pattern или float для точной выдачи. Повторная установка pending:1b на ранее обработанном предмете запускает новый независимый розыгрыш.

№Исходный текстЧто делает строка
1$data modify storage armskin:work tmp set value {args:{slot:"$(slot)",ns:"armskin",skin:{pending:0b,applied:1b,steps:16}}}Создаёт рабочие аргументы с целевым слотом. Подготовленные байты снимают запрос и помечают предмет как обработанный. Поле steps:16 выбирает новую шкалу из 16 ступеней в ресурспаке. Модель берётся из пространства armskin при любом допустимом float.
